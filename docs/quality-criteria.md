# Health Agent Quality Criteria

*Evaluation framework derived from critique of a symptom-assessment agent interaction. Each criterion is operationalized for both the agent prompt (guiding generation) and the judge prompt (evaluating output quality).*

## Prompt-Level Criteria

*These encode general principles and go into agent prompts.*

| Specific Critique | Quality Criterion | Prompt Operationalization | Judge Operationalization |
|---|---|---|---|
| Fires 4+ questions at a user who is in pain; overwhelming and impersonal | **Question Parsimony** | Ask at most 2 clarifying questions per turn. Prioritize the most clinically discriminating questions first. Never use numbered lists of questions. | Count distinct questions per turn. Score 0 if >2 questions in a single response. Score 1 if ≤2 and they target high-priority differentials. |
| Buries the ibuprofen–GI link in hedging language instead of leading with it | **Clinical Relevance Prioritization** | When a plausible causal link exists between a reported medication and symptoms, state it directly in the first sentence. Avoid excessive hedging or conditional phrasing. | Check whether the most probable clinical hypothesis appears in the first 2 sentences of the response. Penalize if buried after generic empathy or re-questioning. |
| Re-asks questions the user already answered (severity, other symptoms) | **Conversational Coherence** | Track all information the user has provided across turns. Never re-ask a question the user has already answered, even partially. Acknowledge prior answers before requesting refinement. | Flag any question that duplicates information already provided by the user in a prior turn. Score 0 if the same question is repeated without acknowledging the prior answer. |
| Final response is a long paragraph when user is in acute distress; buries the action | **Urgency-Proportional Brevity** | When symptoms indicate a potential acute or emergency situation (e.g., severe pain with diaphoresis), limit the response to ≤3 sentences. Lead with the recommended action. Omit empathy fillers. | In acute-severity scenarios, count sentences in the response. Score 0 if >5 sentences. Score 1 if the first sentence contains a concrete action recommendation. |
| Never tells the user to stop taking ibuprofen, the single most useful practical step | **Actionable Completeness** | Every response must include at least one concrete, executable next step the user can take immediately. For medication-related symptoms, explicitly state whether to continue, pause, or stop the medication. | Check whether the response contains at least one specific, actionable instruction (not just "seek medical attention"). For medication-related cases, verify that the response addresses whether to continue/stop the medication. |
| Uses clinical jargon ("gastrointestinal discomfort", "manifest as") with a user in pain | **Register Adaptation** | Use plain, conversational language at approximately an 8th-grade reading level. Avoid medical jargon unless the user introduces it first. Match the user's register. | Flag medical/technical terms not introduced by the user. Score on Flesch-Kincaid readability: target grade 6–8. Penalize formal register when user's messages are casual or distressed. |
| References "the symptom specialist and the medication specialist" — internal architecture leaking into user experience | **Architecture Abstraction** | Never reference internal system components, pipelines, agent names, or routing logic in user-facing responses. Speak as a unified assistant. | Score 0 if the response contains any reference to internal agents, specialists, pipelines, classifiers, or system components. The user should perceive a single coherent assistant. |

## Judge-Only Criteria

*These are specific failure modes to catch in evaluation. They are NOT added to agent prompts to avoid overcorrection — the agent should apply clinical judgment, not follow a rigid checklist.*

| Specific Critique | Quality Criterion | Applies When | Judge Operationalization |
|---|---|---|---|
| Patient says "stomach cramps" but the actual location could be epigastric, periumbilical, or lower abdomen — agent accepts the label at face value | **Symptom Localization Probing** | Patient uses a vague or colloquial anatomical term for their complaint | Check whether the agent accepted a vague or potentially inaccurate anatomical term without follow-up. Score 0 if the agent proceeds with the patient's label (e.g., "stomach") without probing for precise location. Score 1 if the agent asks a localizing follow-up question using concrete landmarks. |
| Agent asks "when did it start?" and "how long have you been experiencing it?" in the same turn — semantically identical questions wasting the patient's time | **Question Non-Redundancy** | Agent asks multiple questions in a single turn | Identify question pairs within a turn or across turns that target the same underlying information (e.g., onset timing and duration of current episode). Score 0 if any two questions are semantically redundant. Score 1 if all questions are informationally distinct. |
| Patient reports pain but agent never explores whether it's stabbing, pressing, burning, or dull; misses the single most diagnostically discriminating axis | **Pain Characterization Depth** | Pain is the chief complaint or a prominent symptom | When pain is reported, check whether the agent explored both quality (stabbing, pressing, burning, dull, cramping, throbbing) and temporal pattern (constant, intermittent, comes and goes completely, waxing/waning) within the first 2 turns. Score 0 if neither was addressed. Score 0.5 if only one axis was explored. Score 1 if both were explicitly asked about using concrete descriptor options. |
